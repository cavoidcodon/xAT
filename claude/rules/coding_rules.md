C coding rules:
  - The local variable name, including function parameters, must be in snake_case.
  - The variable name length must not exceed 20 characters.
  - Static variables must start with "s_" and use camelCase after the prefix.
  - Global variables must start with "g_" and use camelCase after the prefix.
  - In C, identifiers may contain letters, digits, and underscores.
  - In C, identifiers must start with a letter or underscore, and must not start with a digit.
  - Avoid reserved identifiers in C, especially identifiers that begin with an underscore, identifiers with a double underscore, and names reserved by the C standard library.
  - Keep names portable, descriptive, and consistent with the project naming style.
  - Use ASCII letters and underscores for project-wide consistency.
